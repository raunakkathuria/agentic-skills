# Agentic Skills

Reusable Agent Skills for engineering work, built on the
[Agent Skills standard](https://agentskills.io).

## Install

Choose one or more skills to install:

```sh
npx skills add raunakkathuria/agentic-skills
```

Or install one skill:

```sh
npx skills add raunakkathuria/agentic-skills --skill jev-fit-review
npx skills add raunakkathuria/agentic-skills --skill engineering-leadership
npx skills add raunakkathuria/agentic-skills --skill buildwright-philosophy
```

Install as a Claude Code plugin:

```text
/plugin marketplace add raunakkathuria/agentic-skills
/plugin install jev-fit-review@agentic-skills
```

## Skills

| Skill | What it does |
| --- | --- |
| `jev-fit-review` | Audits software for closed-set decisions where TypeSafe's Jev model fits, with evidence and explicit non-fits. |
| `engineering-leadership` | Applies Raunak's engineering leadership principles to engineering decisions and delivery. |
| `buildwright-philosophy` | Applies Buildwright's lightweight engineering discipline to implementation and review work. |
