# Agentic Skills

Reusable Agent Skills for engineering work, built on the
[Agent Skills standard](https://agentskills.io).

## Install

npx skills add raunakkathuria/agentic-skills --skill jev-fit-review

Or as a Claude Code plugin:

/plugin marketplace add raunakkathuria/agentic-skills

/plugin install jev-fit-review@agentic-skills

## Skills

| Skill | What it does |
| --- | --- |
| `jev-fit-review` | Reviews a project and reports where TypeSafe's Jev model fits, and where it does not. |
